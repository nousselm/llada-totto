# 1. Les performances augmentent énormément entre 0-shot et 1-shot

C'est le résultat le plus évident.

BLEU passe de

```text
11.25
```

à

```text
21.54
```

C'est quasiment **un doublement**.

ROUGE-L augmente aussi fortement :

```text
0.355
→
0.458
```

BERTScore :

```text
0.895
→
0.913
```

**Interprétation**

Le modèle LLaDA bénéficie énormément d'un seul exemple (one-shot). Cela montre qu'il sait exploiter les démonstrations fournies dans le prompt.

---

# 2. Après 1-shot, le gain est très faible

Entre

1-shot

↓

3-shot

↓

5-shot

↓

10-shot

on observe :

BLEU

21.54

La progression devient presque nulle.

ROUGE et BERTScore suivent exactement le même comportement.

Autrement dit :

> ajouter davantage d'exemples ne permet quasiment plus d'améliorer les performances.

C'est une observation assez classique dans les LLM.

---

# 3. Le 10-shot ne fait pas mieux

C'est intéressant.

BLEU diminue :

```text
21.95
↓

20.73
```

Pourquoi ?

Plusieurs hypothèses :

* le contexte devient plus long ;
* le modèle est "pollué" par des exemples moins pertinents ;
* certaines démonstrations récupérées sont moins similaires ;
* effet de saturation.

Il sera intéressant de voir si QLoRA réduit cette saturation.

---

# 4. BERTScore est très élevé

Tous les scores sont autour de

```text
0.91
```

C'est excellent.

Cela signifie que :

> les phrases générées sont très proches sémantiquement des références.

Autrement dit,

même lorsque BLEU n'est pas parfait,

la génération reste proche du sens attendu.

C'est une bonne nouvelle.

---

# Ce résultat mérite d'être vérifié

Avant d'en tirer des conclusions, je voudrais vérifier que le NLI est utilisé dans le bon sens.

Pour le NLI il faut faire

```
premise = référence

hypothesis = génération
```

et non l'inverse.

Sinon les probabilités changent complètement.

C'est la première chose que je vérifierais.

---

# 6. Même si le NLI est correct...

...cela peut vouloir dire quelque chose d'intéressant.

Le modèle produit davantage de détails.

BLEU augmente.

ROUGE augmente.

Mais il ajoute aussi des informations qui ne sont pas dans la référence.

Le classifieur NLI considère alors ces phrases comme des contradictions.

C'est un phénomène assez fréquent.

### Une dernière remarque importante

Le seul résultat qui m'interpelle est le **NLI**. La baisse de l'entailment et la hausse des contradictions lorsque le nombre de shots augmente n'est pas le comportement auquel je m'attendrais. **Avant d'interpréter scientifiquement ces chiffres, je vérifierais l'implémentation du calcul NLI** (ordre prémisse/hypothèse, modèle utilisé, etc.). Une fois ce point validé, on pourra commenter ces résultats avec beaucoup plus de confiance.
